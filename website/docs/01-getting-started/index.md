Three steps, in order:

1. [Installation](installation.md) — build the binary from source.
2. [First config](first-config.md) — a complete minimal config with an L4 listener, an HTTP listener, an h3 listener and the admin endpoint.
3. [Verify](verify.md) — curl it, drive it with an HTTP/3 client, and read the admin scrape.

If you are in a hurry, the [quick start](/#quick-start) on the front page is the whole thing in one screen.
