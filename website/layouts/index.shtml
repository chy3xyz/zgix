zgix

A zero-allocation L4/L7 edge proxy with experimental HTTP/3, written in Zig. Every pool reserved at startup — the serving path allocates nothing, and exhaustion sheds load at a defined rung of the ladder.

Zero-allocation serving

All memory is reserved at startup; the request path allocates nothing. Pool sizes are closed-form functions of compile-time constants, printed in the banner and asserted against RLIMIT_NOFILE.

HTTP/3 over QUIC

Experimental h3_listeners terminate QUIC-TLS and proxy each request over a pooled plaintext-or-TLS HTTP/1.1 leg — observed like the TCP path, verdict counters and access log included.

SNI multi-tenant TLS

Terminate TLS 1.3 with up to 16 certificate pairs per listener — or relay blind by SNI, so one :443 fronts many TLS services without zgix ever holding key material.

WebSocket tunnels

An opt-in upgrade relay with its own bounded tunnel pool. Long-lived sessions pin their own buffers and can never starve HTTP of relay slots or upstream leases.

Declarative JSON config

One file, unknown fields refused, --check prices memory and fds before a port is bound. No config reload: replace the process behind SO_REUSEPORT instead.

Prometheus-grade observability

zgix_* counter families, per-endpoint health gauges, RED histograms, a JSON access log, a bounded log tail on the scrape — and a bundled control panel that reads it all.
